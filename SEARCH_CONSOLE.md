# Getting TrackItMX Indexed Faster

Once `https://trackitmx.com/` is live:

1. Open Google Search Console.
2. Add `trackitmx.com` as a Domain property.
3. Verify ownership using the DNS record Google gives you.
4. Submit this sitemap:

- `https://trackitmx.com/sitemap.xml`

5. Use URL Inspection to request indexing for:

- `https://trackitmx.com/`
- `https://trackitmx.com/support/`
- `https://trackitmx.com/privacy/`

## Notes

- Search indexing is not instant.
- The site already includes `robots.txt`, `sitemap.xml`, canonical URLs, and basic metadata to help crawlers.
- If you edit pages later, you can request indexing again for the updated URLs.
